# 🏦 Secure Banking API

Production-ready REST API built with Spring Boot 3, Spring Security + JWT, and JPA.

### Features
- 🔐 JWT Authentication (Register/Login)
- 👤 User & Account Management
- 💸 Deposit / Withdraw / Transfer
- 📜 Transaction History
- 🛡️ BCrypt Password Encryption + Stateless Security
- 🐳 Docker & MySQL Ready

### Tech Stack
Java 21 • Spring Boot 3 • Spring Security • JWT • MySQL/H2 • Maven • Docker

### Quick Start
```bash
./mvnw spring-boot:run
# API runs at http://localhost:8080
